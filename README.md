Soy estudiante de Ingeniería de Sistemas y estoy construyendo, paso a paso, mi camino hacia el desarrollo Full Stack. Este portafolio reúne mi punto de partida: una página personal sencilla, hecha para aprender los fundamentos y documentar cómo voy creciendo.

## Objetivo de aprendizaje

Mi objetivo actual es entender progresivamente cómo se construye el software, no solamente llegar a un resultado que funcione.

Estoy fortaleciendo mis fundamentos de desarrollo web, JavaScript, Git y GitHub. Más adelante continuaré explorando frontend moderno, backend, bases de datos, APIs, testing, deployment y arquitectura.

Este proyecto irá cambiando conmigo a medida que aprenda nuevas herramientas y pueda convertirlas en mejoras reales.

## Sobre el proyecto

Este repositorio contiene la primera versión de mi portafolio personal. La página presenta:

- Una breve presentación personal.
- Enlaces a GitHub, LinkedIn y un enlace de Resume.
- Mi experiencia como Quality Analyst en Cibergestión Colombia.
- Mi formación en Ingeniería de Sistemas y mi proceso de autoformación.
- El proyecto actual del portafolio y las tecnologías usadas en él.

Por ahora es una página estática, sin JavaScript ni frameworks. Su propósito principal es servir como base para practicar, observar mis avances y construir sobre fundamentos que pueda comprender.

## Ejecutar el proyecto localmente

El proyecto no requiere instalación de dependencias ni un proceso de compilación.

### Opción 1: abrir el archivo directamente

1. Descarga o clona este repositorio.
2. Abre `index.html` en un navegador.

### Opción 2: usar un servidor local

Desde la carpeta raíz del proyecto, ejecuta:

```bash
python -m http.server 8000
```

Después, abre [http://localhost:8000](http://localhost:8000) en el navegador.
